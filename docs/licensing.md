# Licensing: source code vs generated assets

GITCRAFT's source code and its generated assets are licensed separately. This page records which licence applies to
what, and the result of the asset provenance audit done for the release.

## 1. Source code: MIT

[`LICENSE`](../LICENSE): MIT, Copyright (c) 2026 scottyfncodes. It covers this repository's source code and
documentation: Python, JavaScript, shell scripts, CSS/HTML templates, configuration, tests (the test code), and docs.

It does **not** cover:
- the asset files listed in [`asset-inventory.json`](asset-inventory.json) (section 3);
- third-party components that carry their own licences, which stay under them:
  - `forgecraft/ui/vendor/three/` (three.js, MIT, © three.js authors);
  - the ArtCraft CLIs built from [github.com/storytold](https://github.com/storytold) and published on the `bin`
    branch (their upstream licences);
  - runtimes and models installed at setup time. Their audits are in [3d-licensing.md](3d-licensing.md),
    [forgecraft-licensing.md](forgecraft-licensing.md) and [studio-acquisition.md](studio-acquisition.md).

## 2. What GITCRAFT makes for your projects

Files the tools generate for a project are not part of GITCRAFT and are not covered by its MIT licence. Each
department run writes a `<name>.studio.json` (3D: the library's `asset.json`). That record lists the tools and their
licences, the inputs and an output statement such as "owned by the requesting project". That statement describes
provenance; it is not a licence grant. Inputs keep their own licences (a Mixamo clip, a photographed object, a
CC-licensed texture), and the copyright status of procedurally or AI-generated output depends on jurisdiction. The
owner of the project that commissioned an asset decides its licence. AssetCraft's `license_report` lists anything
without a recorded licence.

## 3. Asset audit (release, 10 November 2026)

**Scope.** Every committed file with a media extension: AssetCraft's formats plus `jpg`, `tmj`, `tmx` and `ldtk`.
That is **952 files**. The GITCRAFT report's "1,118 assets with no known licence" also counted untracked local output
(`gitcraft-out/`, scratch runs); those are not part of the repository or a release.

**Method.** For each file, the provenance evidence that exists: a department run record (`.studio.json`), a 3D
library record (`asset.json`), a `.license.json` sidecar, or none. No file has a licence grant, and none was assigned
one. The per-file result, with its evidence path, is [`asset-inventory.json`](asset-inventory.json).

**Findings.**
- No third-party content was found in the generated assets. The 12 files labelled with Mixamo contain no
  Mixamo data. No paid or non-commercial model output was found (music and SFX come from GITCRAFT's own synthesizer;
  voice from Kokoro, Apache-2.0).
- 21 files depict other repositories' games. Their rights belong to those projects. The games share a GitHub owner
  with this repository, but their licences were not verified here.
- Nothing in the repository grants a licence for any of the 952 assets.

**Release status: the source code is licensed (MIT). The assets are not cleared for redistribution.** Before they
can be, the rights holder must:
1. decide a licence for groups A, B and D, if they want them redistributed (e.g. CC0 or CC-BY-4.0), and record it
   (a `LICENSE.assets.json` per folder, or per-file `.license.json` sidecars, both read by AssetCraft);
2. confirm the rights in the 21 group C captures with the depicted projects, or remove those captures from
   redistributed copies;
3. for the 3 AI voice files, note that copyright protection of AI-generated output varies by jurisdiction.

Until then, a copy of this repository may use the code under MIT, but it has no licence to redistribute the asset
files beyond what the law otherwise allows.
