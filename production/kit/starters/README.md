# Starters

Copied by `foundation.scaffold` into a **new, empty** project only (never into an existing one, never over a file).
`{{TITLE}}`, `{{SHORT}}` and `{{SLUG}}` are filled from the spec. Each starter already meets the app standards
(docs/app-standards.md): lang, viewport, title, a visible error path, the HaveAnApp byline, a manifest and the icon
links the App Icon Studio fills, 44 px touch targets, light/dark tokens, reduced motion, and a feature-check file.

| Starter | Chosen for |
|---|---|
| `static-app` | apps and sites with no framework (the default) |
| `canvas-game` | 2D games on canvas |
| `vite-react` | apps that asked for React (the build installs and commits the lockfile) |
