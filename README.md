# GITCRAFT API Discovery: published catalogue

`apis.json` is generated by `.github/workflows/api-catalog.yml` on `main` and read by the API Discovery page.
Do not edit it by hand: the next run replaces this branch.

The list of APIs, their descriptions and the Auth / HTTPS / CORS columns come from
[public-apis](https://github.com/public-apis/public-apis) (MIT, Copyright (c) 2022 public-apis).
The link checks are GITCRAFT's own: one request per documentation link on the date in the file.
